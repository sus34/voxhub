# Установка: если что-то пошло не так

Сначала — `voxhub status` и `voxhub logs` (выход — Ctrl+C). Почти всё видно там.

### Сайт не открывается, а установщик сказал «Готово»

У многих хостеров есть **свой файрвол в панели**, отдельно от сервера. Установщик
в конце печатает список портов — открой их там. Чаще всего забывают UDP.

### «Не поднялось за 3 минуты», в `voxhub logs caddy` ошибки про ACME / challenge

Let's Encrypt не смог проверить домен. Причины по частоте:

- в панели хостера закрыт порт 80 (или 443) — открой;
- свой домен ещё не указывает на сервер — нужна A-запись `домен → IP`, подожди
  обновления DNS и сделай `voxhub restart`;
- слишком много попыток за час — Let's Encrypt временно отказывает, подожди час.

### Порты 80 и 443 оба заняты (VPN, сайт)

Сертификат через Let's Encrypt тогда получить нельзя — он проверяет домен только по ним.
Варианты: освободить 80 (обычно он нужен только для редиректа на https), или выпустить
сертификат самому через certbot — установщик спросит путь к нему и будет им пользоваться.

### «Не скачались образы с Docker Hub»

Часть российских хостеров не достаёт до Docker Hub. Установщик предлагает включить
зеркало `mirror.gcr.io` — соглашайся. Вручную: в `/etc/docker/daemon.json`

```json
{ "registry-mirrors": ["https://mirror.gcr.io"] }
```

и `systemctl restart docker`.

### Звонок подключается, но у кого-то одного нет звука или видео

Это его сеть режет UDP (мобильный интернет, офис). Такие подключаются через TURN —
проверь, что в файрволе хостера открыт `TURN_TLS_PORT` (5349 по умолчанию).

### Переехать на другой сервер

1. На старом: `voxhub backup` и скопируй файл из `/opt/voxhub/backups/` к себе.
2. На новом: поставь voxhub установщиком, затем `voxhub restore <файл>`.

Аккаунты, каналы и приглашения переедут. Ссылку друзьям придётся дать новую, если
поменялся адрес.
